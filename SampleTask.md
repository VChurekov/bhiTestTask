# Задача анализа данныых

## Контекст
Доступ к данным через MCP `1c-odata`.

## Задача

«Проанализируй данные в тестовой базе 1С:УТ. Мне нужно понять, почему по номенклатуре **Хлеб ржаной** на складе **Центральный склад** система может показывать отрицательную потребность в обеспечении заказов.

## Шаги

1. Сначала получи текущий **свободный остаток** этой номенклатуры на указанном складе (из соответствующего регистра остатков).
2. Затем найди все **активные заказы клиентов** (или документы «Заказ клиента»), в которых эта номенклатура зарезервирована или должна быть отгружена с этого склада. Выведи список этих заказов, количество товара в них и статус заказа.
3. Сравни общее зарезервированное количество с остатком. Если сумма резервов превышает остаток, это и есть причина «дефицита» в системе, даже если товар лежит на полке.
4. Выведи итоговую таблицу: `Номенклатура | Склад | Остаток | Зарезервировано | Разница (Остаток - Резерв) | Список заказов`.

## Вывод

объяснить причину отрицательной потребности — за счёт резерва, наличия под заказ или комбинации.
Если данных нет — написать прямо, фиктивные значения НЕ подставлять.

## Результат

- Дополнительно зафиксируй время выполнения задачи в формате `HH:mm:ss`.
- Запиши полный лог выполнения в `tmp/log.log`
- Дополнительно сохрани результат в файл `tmp/result.md`
